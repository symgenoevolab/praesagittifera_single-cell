### This directory includes code:


- Pna_rsd_construction.Rmd [R script] (Figure 1c)

Generate a Seurat RDS object and UMAP plots from the single-cell RNA-seq dataset of _Praesagittifera naikaiensis_ deposited in NCBI GEO (GSE351334).



- Pna_DoHeatmap.Rmd [R script] (Figure 1d)

Generate a gene-expression heatmap with the top 10 marker genes for each cell type.



- Alge_region_segmentation.ijm [Fiji macro script] (Figure 2d)

Detects algal autofluorescence in confocal images and quantifies algal density.
